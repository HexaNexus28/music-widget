# YouTube Music Widget

**Une application desktop pour écouter de la musique depuis YouTube, construite avec React, Vite et Electron.**

**Pourquoi réinventer la roue ?**
Parce qu'on peut la rendre **plus ronde, plus rapide, et plus adaptée à nos besoins**.

## 📌 Description

Cette application permet de :

- Lire des musiques directement depuis YouTube.
- Fonctionne en local, sans besoin d'un navigateur.

**Technologies utilisées** :

- Frontend : React, Vite, TailwindCSS
- Desktop : Electron
- API : YouTube IFrame Player API

---

## 🎯 Pourquoi utiliser Music Widget ?

| **Avantage**             | **Description**                                                                 |
| ------------------------ | ------------------------------------------------------------------------------- |
| **Sans distraction**     | Pas de publicités, pas de suggestions intrusives, pas de commentaires toxiques. |
| **Personnalisable**      | Thèmes, raccourcis clavier, et intégrations futures (ex: Spotify, Apple Music). |
| **Local et privé**       | Tes données restent sur ton appareil, sans tracking par YouTube.                |
| **Open-source**          | Le code est ouvert aux contributions : [Lien GitHub](#).                        |
| **Multi-tâche optimisé** | Lecture en arrière-plan, mini-player, ou intégration dans une barre latérale.   |

## 🚀 Fonctionnalités Actuelles

- **Lecture de vidéos YouTube** : Intègre un lecteur vidéo/musique directement depuis YouTube.
- **Interface fluide** : UI intuitive et responsive, conçue pour une expérience utilisateur optimale.
- **Exécutable (.exe)** : Application packagée pour une utilisation hors navigateur (grâce à Electron).
- **Gestion des erreurs** : Messages clairs et feedback visuel pour une utilisation sans frustration.
